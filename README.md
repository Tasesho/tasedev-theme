# TaseDev Theme

A fork of the [System24 Discord theme](https://github.com/refact0r/system24), recolored with the TaseDev palette and styled with rounded borders.

## Installation

Import `tasedev.theme.css` in your Discord client’s theme settings. The stylesheet loads System24 from its upstream URL, so an internet connection is required for the base theme.
